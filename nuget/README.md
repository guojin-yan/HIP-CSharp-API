# JYPPX.ROCm.HIP.CSharp.API

This local `0.9.0` package is the managed-only M8.1 release candidate for API-freeze review. It is not a published stable release. It contains the single `JYPPX.ROCm.HipSharp` assembly for all 15 declared target frameworks, bilingual XML documentation, this README, the project logo, and the Apache-2.0 license file.

The managed API binds HIP Runtime, memory, stream/event, stream-ordered allocation, managed memory, peer access, graph capture, Module/Launch, and HIPRTC functions. The package does not contain ROCm, an AMD driver, a code object, or any native binary, and it does not force a dependency on a runtime package. Earlier M4-M6 GPU results are historical evidence only; the exact 0.9.0 Core and Linux Runtime candidate pair remains non-publishable until a newly Owner-authorized isolated cloud gate passes.
