# JYPPX.HIP.CSharp.API

This local `0.0.0-preview.1` package is the M0 engineering baseline. It contains the `JYPPX.HipSharp` and `JYPPX.HipSharp.Native` assemblies for all 15 declared target frameworks, their XML documentation, this README, the project logo, and the Apache-2.0 license file.

No HIP function is bound or called yet. The package does not contain ROCm, an AMD driver, or any native binary. Runtime package candidates remain disabled until provenance, dependency, licensing, and GPU validation gates are complete.
