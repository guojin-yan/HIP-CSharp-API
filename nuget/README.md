# JYPPX.ROCm.HIP.CSharp.API

This source builds the unpublished `0.11.0-dev` managed Core package, with a single `JYPPX.ROCm.HIP.CSharp.API` assembly for all 15 declared target frameworks and the `JYPPX.ROCm.HipSharp` namespace. It also contains bilingual XML documentation, this README, the project logo, and the Apache-2.0 license file. The immutable published `0.10.0` release is a separate baseline.

The managed API binds HIP Runtime, memory, stream/event, stream-ordered allocation, managed memory, peer access, graphs, Module/Launch, HIPRTC and advanced interop. The package does not contain ROCm, an AMD driver, a code object, or any native binary, and it does not force a dependency on a runtime package. Development `0.11.0-dev` exposes 122 types and 1,372 members, with advanced ownership and graph-state fixes and versioned Windows HIPRTC loading. Local Windows and WSL2 development workloads are separate from the published `0.10.0` exact-package evidence. On ROCm 7.2.1, avoid `hipMemRetainAllocationHandle` retained-allocation ownership until a runtime containing the upstream reference-count fix is used.
