# HipSharp API Documentation / API 文档

HipSharp wraps the foundational AMD HIP Runtime Direct C ABI for .NET. The current `0.0.0` engineering candidate provides initialization, version, device, synchronous memory, synchronization, loading diagnostics, and native error APIs.

HipSharp 为 AMD HIP Runtime 的基础 Direct C ABI 提供 .NET 封装。当前 `0.0.0` 工程候选包提供初始化、版本、设备、同步内存、同步、加载诊断与原生错误 API。
