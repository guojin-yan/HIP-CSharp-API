# HipSharp API Documentation / API 文档

HipSharp wraps AMD HIP Runtime and HIPRTC Direct C ABIs for .NET. The managed-only `0.0.0` candidate covers runtime, device, memory, stream/event, runtime compilation, module, and kernel APIs. M5 adds an audited but still disabled Linux ROCm 7.2.1 runtime-package supply chain.

HipSharp 为 AMD HIP Runtime 与 HIPRTC Direct C ABI 提供 .NET 封装。managed-only `0.0.0` 候选覆盖 runtime、设备、内存、stream/event、运行时编译、module 与 kernel API；M5 新增已经审计但仍禁用的 Linux ROCm 7.2.1 runtime package 供应链。
