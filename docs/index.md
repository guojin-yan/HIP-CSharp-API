# HipSharp API Documentation / API 文档

HipSharp wraps AMD HIP Runtime and HIPRTC Direct C ABIs for .NET. Managed-only Core `0.9.0` is a local API-freeze release candidate, not a published stable release. Linux Runtime `7.2.1` remains guarded and unpublished; its current exact-SHA candidate still requires newly Owner-authorized isolated host and PRoot validation. Earlier M4-M6 cloud results are historical evidence only. Windows remains static-only and GPU-unvalidated.

HipSharp 为 AMD HIP Runtime 与 HIPRTC Direct C ABI 提供 .NET 封装。managed-only Core `0.9.0` 是本地 API 冻结发布候选，不是已发布稳定版。Linux Runtime `7.2.1` 继续受控且未发布；当前绑定精确 SHA 的候选仍需 Owner 新授权的隔离 host 与 PRoot 验证。M4-M6 云端结果仅为历史证据。Windows 仍为 static-only，未经过 GPU 验证。
