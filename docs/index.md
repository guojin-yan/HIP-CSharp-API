# HipSharp API Documentation / API 文档

HipSharp is a planned .NET wrapper for the AMD HIP Direct C ABI. The current `0.0.0` package is an engineering baseline and does not yet call HIP or provide GPU functionality.

HipSharp 计划为 AMD HIP Direct C ABI 提供 .NET 封装。当前 `0.0.0` 包是工程基线，尚未调用 HIP，也不提供 GPU 功能。
