# HipSharp API Documentation / API 文档

HipSharp wraps AMD HIP Runtime and HIPRTC Direct C ABIs for .NET. The current `0.0.0` engineering candidate provides initialization, device and synchronous memory APIs plus runtime compilation, code-object loading, module/function ownership, and default-stream kernel launch.

HipSharp 为 AMD HIP Runtime 与 HIPRTC Direct C ABI 提供 .NET 封装。当前 `0.0.0` 工程候选包提供初始化、设备、同步内存，以及运行时编译、code object 加载、module/function 所有权和 default stream kernel launch API。
