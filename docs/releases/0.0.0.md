# 0.0.0 local candidate

This is an engineering candidate for local validation. It has not been published to nuget.org.

Included:

- Direct multi-target project baseline for 15 requested TFMs.
- A single assembly with bilingual XML documentation for every TFM in the local core nupkg.
- Deterministic `LibraryImport`/`DllImport` declarations for HIP Runtime, Module/Launch, and HIPRTC from one manifest.
- Managed initialization, device, synchronous memory, runtime compilation, code-object, module, kernel, loading-diagnostic, and separate Runtime/HIPRTC error APIs.
- Checked ownership and final-release protection for device memory, HIPRTC programs, and modules.
- A complete in-memory HIPRTC VectorAdd sample with per-iteration CPU comparison and an expected compiler-failure mode.
- Package content audit and clean consumer restore/build checks for representative TFMs.
- M1 and M2 Radeon Cloud validation on authorized Ubuntu 24.04.4, ROCm 7.2.1, HIP 7.2.53211, and `gfx1100` sessions.
- Required Runtime/HIPRTC symbol and official-header ABI verification, device/memory checks, five VectorAdd lengths x 20 repeats, and expected compile-failure log capture.
- Disabled runtime package manifests and a hard pack guard.

Not included:

- Streams, events, asynchronous operations, extended device properties, or AMD native binaries.
- A validated Linux or Windows runtime package.
- A nuget.org publication or GitHub Release.
