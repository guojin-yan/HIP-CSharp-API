# 0.9.0 Linux release candidate / Linux 发布候选

`JYPPX.HIP.CSharp.API` version `0.9.0` is a local release candidate for public API freeze review. It is not a published stable release. The optional Linux runtime candidate remains `JYPPX.HipSharp.Runtime.linux-x64` version `7.2.1` and is also unpublished.

`JYPPX.HIP.CSharp.API` `0.9.0` 是用于公开 API 冻结审查的本地发布候选，并非已发布稳定版。可选 Linux runtime 候选仍为 `JYPPX.HipSharp.Runtime.linux-x64` `7.2.1`，同样未发布。

The committed API snapshot is checked against all 15 target frameworks. The selected managed owners are driven by a 79-entry interop manifest: 70 HIP Runtime and 9 HIPRTC entries. M8.2 added 13 Runtime entries for memory information, pitched allocation, memset, and 2D/3D copy; M8.3 adds 11 Runtime entries for memory-pool creation, policy, access, trim, and pool-backed allocation. The complete low-level model remains 459 HIP Runtime and 18 HIPRTC C ABI declarations from the pinned official headers. The formal/diagnostic/sample-only/internal classification, ownership and disposal rules, thread-safety limits, error model, and permitted pre-freeze changes are recorded in the [API freeze review](../guides/api-freeze.md).

Local candidate requirements are fail-closed:

- one central version source for Core `0.9.0`, Linux Runtime `7.2.1`, and the disabled Windows Runtime `7.2.0` skeleton;
- deterministic interop generation from the 79-entry owner manifest plus the pinned-header complete model, with identical public API on all TFMs;
- build, unit, quality, package, clean-consumer, documentation, source-provenance, closure, license, SBOM, size, and static Windows gates;
- exact Git commit metadata in both packages and a clean-SHA runtime-candidate attestation;
- `publishable=false` until the exact Core and Runtime packages pass a newly Owner-authorized isolated host and PRoot GPU gate.

The M8.1 Radeon Cloud result at `e78854f` remains historical evidence for all 477 low-level symbols and the previous managed surface. It does not validate the 13 M8.2 or 11 M8.3 managed entry paths, a newly built 0.9.0 Core package, or a runtime package bound to a different commit. M8.3 currently has deterministic fake-native pool tests, static ABI source updates, and managed compilation evidence, with no new real Runtime symbol or GPU execution result. Windows remains disabled, inventory-empty, static-audit-only, and GPU-unvalidated. No support breadth or performance claim is made.
