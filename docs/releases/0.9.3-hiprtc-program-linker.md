# 0.9.3 HIPRTC Program and Linker / 0.9.3 HIPRTC Program 与 Linker

It promotes four Program functions (`hiprtcAddNameExpression`, `hiprtcGetLoweredName`, `hiprtcGetBitcodeSize`, `hiprtcGetBitcode`) and five Linker functions (`hiprtcLinkCreate`, `hiprtcLinkAddFile`, `hiprtcLinkAddData`, `hiprtcLinkComplete`, `hiprtcLinkDestroy`) from `managed-next` to `managed`.

`HipRtcLinker` is a separate disposable owner. It retains unmanaged copies passed through `AddData`, copies the `LinkComplete` output before the state is destroyed, rejects post-completion mutation, and permits retry after an explicit destroy failure. `HipRtcProgram` copies lowered names and bitcode into managed storage.

`HipRtcLinker` 是独立 disposable owner。它保留传给 `AddData` 的非托管副本，在 state 销毁前复制 `LinkComplete` 输出，拒绝完成后的修改，并允许显式销毁失败后重试。`HipRtcProgram` 把 lowered name 和 bitcode 复制到托管存储。
