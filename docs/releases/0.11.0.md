# 0.11.0 preparation / 发布准备

Source remains `0.11.0-dev`; **0.11.0 has not been published or authorized for publication**. Core `0.10.0` and Linux Runtime `7.2.1` remain the public baseline.

## Changes under validation / 本轮修复

- Correct application-local Windows HIPRTC version discovery when the directory ends in a separator. This fixes flattened RID publish and .NET Framework 4.8 deployments with `hiprtc0716.dll`.
- Package consumers cover no-RID publish, RID publish through `dotnet` and apphost, and Windows .NET Framework 4.8. Missing HIPRTC remains a required failing negative case.
- Release upload uses a reviewed candidate artifact, exact package hashes, dual-platform receipts and an independently reviewed manifest hash. It rejects existing public versions and compares every published package entry except `.signature.p7s`.
- The current API baseline is 122 types / 1,372 members across 15 TFMs. Older 1.0.0 planning snapshots are historical.

## Validation scope and remaining gates / 范围与剩余门禁

Local tests use Windows x64 and Ubuntu 24.04 under WSL2, W7900/gfx1100, TheRock SDK 10.1.0 (HIP Runtime 7.16.26385, HIPRTC 9.0). The local Runtime packages are development dependencies. Windows .NET 10 and .NET Framework 4.8 run GPU kernels; Linux/WSL2 .NET 10 runs GPU workloads. Other TFMs are build/API compatibility targets until separately exercised at runtime.

Managed memory is a capability skip on both hosts. Linux array/texture/surface paths remain a skip because `hipMallocArray` returns `NotSupported`; that limitation has not been treated as fixed. Cooperative launch and multi-GPU paths depend on device capability. Bare Linux/KFD, other architectures, IPC, external memory/semaphore and graphics interoperability remain experimental until their own integration evidence exists.

Before a stable release, choose a version and validate its exact clean-commit package, review ABI and support evidence, and obtain publication authorization. A claim of compatibility with published Runtime `7.2.1` needs a fresh regression using that exact Runtime; local 10.1.0 tests cannot supply it. New native Runtime redistribution needs the separate [provenance and license work](../guides/runtime-redistribution.md). The [Core workflow](../guides/core-release-candidate.md) does not publish Runtime packages.
